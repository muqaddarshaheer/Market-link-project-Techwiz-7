1. Project Overview

MarketLink is a web platform that connects local farmers-market growers with customers. Customers browse markets and produce, reserve pickup pre-orders, and pay the farmer in person at the stall. Farmers manage stall profiles, stock, and order workflow. Admins approve farmers, moderate listings, and review platform reports.

Core scope rules
  • No online / card payment gateway — payment is always in person at pickup.
  • No delivery or courier — customers collect at the market stall.
  • Farmers must be approved by an admin before products appear publicly.
  • Reviews can be left after a completed pickup order.

2. Problem Statement

Traditional farmers markets rely on paper lists, unclear stock, and weak communication between growers and buyers. Customers do not know what will be available; farmers cannot plan packing; admins lack one place to moderate stalls and announcements.

MarketLink replaces that friction with digital browse, reserve, and pickup coordination while keeping the real-world payment and collection model of a local market.

3. Objectives

  • Let customers discover markets, farmers, and seasonal produce quickly.
  • Allow pre-orders with stock checks and pickup date/slot selection.
  • Give farmers tools for inventory, slots, order accept/ready/complete, and reviews.
  • Give admins control over approvals, markets, categories, products, reviews, announcements, FAQs, and reports.
  • Provide a responsive, dark-mode capable, app-like shopping experience (AJAX cart, live filters, live search).

4. Users and Roles

4.1 Guest (not logged in)

  • Browse home, about, contact, markets, farmers, products.
  • Live search suggestions and full search results page.
  • Guest cart and guest checkout (name, phone, address, pickup).
  • Quick one-step order on a product page.
  • Login / register as customer or farmer.

4.2 Customer

  • Dashboard, favorites, notifications, profile, password.
  • Database cart, checkout, order history, cancel/reorder (when allowed), printable invoice.
  • Leave reviews on completed orders; mark reviews helpful.

4.3 Farmer

  • Dashboard, product create/update/delete, weekly stock template.
  • Order queue: accept, decline, ready, complete.
  • Pickup slots, insights, review replies, stall profile.
  • Pending farmers cannot list products until admin approval.

4.4 Admin

  • Users (status, PIN), farmers (approve / suspend / update / delete).
  • Markets, categories, products, review moderation.
  • Orders overview; payment status marking for cash-at-stall tracking.
  • Announcements, chatbot FAQs, settings, Chart.js reports and CSV export.

6. System Architecture

MarketLink follows the Laravel MVC pattern:

  • Routes: routes/web.php (main UI), routes/api.php (read-only lists).
  • Controllers: public, auth, customer, farmer, and admin controllers under app/Http/Controllers.
  • Models: Eloquent models in app/Models (User, FarmerProfile, Market, Product, Cart, Order, Review, etc.).
  • Views: Blade templates in resources/views with layouts for app, customer, farmer, admin, and auth.
  • Middleware: role checks protect /customer/*, /farmer/*, /admin/*.
  • View composers: AppServiceProvider shares site settings, cart count, announcements, and unread notifications.

7. Main Features

7.1 Public website

  • Home: featured markets, farmers, products, harvest calendar, farmer story video, continuous review marquee, CTA.
  • About page with story sections and featured growers/produce.
  • Contact form (rate throttled).
  • Privacy, terms, sitemap.
  • Dark / light theme toggle (stored in localStorage).
  • FAQ keyword chatbot (floating widget).

7.2 Product browsing (shop UX)

  • Product grid with live AJAX filters (category, market, price, day, rating, quality, farmer, in-stock, sort, search).
  • Partial HTML refresh — no full page reload while filtering.
  • AJAX cart add / update / remove with toast + live badge.
  • Mobile filter drawer and bottom dock (Home, Browse, Cart, Account).
  • Card reveal animations (respects reduced-motion preference).

7.3 Search

  • Navbar live suggest via /search/suggest (products, farmers, markets).
  • Enter / “See all results” opens unified /search page.

7.4 Cart and checkout

  • Customer cart in database (carts, cart_items).
  • Guest cart in session (ml_guest_cart).
  • Checkout: pickup date, slot, optional note.
  • OrderService splits cart into one order per farmer + market.
  • Stock reserved on place; copy reminds users to pay at the stall.
  • Multi-stall carts show a shared pickup-window warning.

7.5 Harvest calendar

  • Interactive season guide on the home page (grid, filters, favorites, upcoming, modal).
  • Dark-theme readable cream card and high-contrast popup.

7.6 Authentication

  • Customer and farmer registration.
  • Email/password login; optional 4-digit PIN login where seeded/configured.
  • Password reset (log mailer writes links to storage/logs/laravel.log locally).
  • Throttled login and sensitive posts.

8. Order Lifecycle

  1. Customer/guest adds available products to cart.
  2. Checkout chooses pickup date and time slot.
  3. System creates order(s), updates stock, notifies farmer.
  4. Farmer accepts (or declines) the order.
  5. Farmer marks order ready for pickup.
  6. Customer collects and pays in Pakistani Rupees (Rs) at the stall.
  7. Farmer marks order complete.
  8. Customer may leave a review; admin can moderate reviews.

11. Installation and Setup (XAMPP)

  1. Place project under htdocs, e.g. C:\xampp\htdocs\marketlink-techwiz-7.
  2. Copy .env.example to .env; set DB name, user, password.
  3. Run composer install.
  4. Run php artisan key:generate.
  5. Create MySQL database, then php artisan migrate --seed.
  6. Run php artisan storage:link.
  7. Start Apache + MySQL in XAMPP.
  8. Open http://localhost/marketlink-techwiz-7/public/ (or php artisan serve).
  9. Production: HTTPS, correct APP_URL, secure session cookies.

13. Security Measures

  • Password hashing (bcrypt via Laravel).
  • CSRF tokens on forms and AJAX (csrf-token meta + header).
  • Role middleware for customer / farmer / admin areas.
  • Server-side validation; Blade escaping by default.
  • Login and contact/chatbot throttling.
  • Upload type/size limits where images are accepted.
  • No card payment surface — reduces PCI compliance scope.

14. UI / UX Highlights

  • Brand styling with Fraunces + Manrope fonts.
  • Dark theme readability across About, footer, harvest calendar, and shop.
  • Continuous customer review marquee on home.
  • Mobile bottom dock for app-like navigation.
  • Toast notifications for AJAX cart actions.

15. Read-only API

JSON endpoints under /api expose markets and products for a possible future mobile client. Cart and checkout remain web/session based in the current build.

16. Limitations

  • No card gateway or digital wallet payments.
  • No delivery / courier logistics.
  • Chatbot is keyword FAQ matching, not generative AI.
  • Password reset needs real SMTP in production.
  • Guest cart is session-based and cleared if the session is lost.

17. Suggested Test Plan

  • Guest: browse products → live filter → AJAX Add → guest checkout.
  • Customer: login → cart → checkout → order timeline → review.
  • Farmer: accept → ready → complete; update stock; reply to review.
  • Admin: approve farmer, post announcement, moderate review, export CSV.
  • Theme: dark mode on About, footer, harvest calendar, products.
  • Mobile: filter drawer + bottom dock on products page.

18. Conclusion

MarketLink is a complete farmers-market pre-order platform focused on local pickup and in-person payment. It covers public discovery, customer and guest ordering, farmer operations, and admin governance, with a modern responsive UI including live browse and AJAX cart behaviour. It is suitable for TechWiz / academic demonstration and for real stall pickup workflows.
