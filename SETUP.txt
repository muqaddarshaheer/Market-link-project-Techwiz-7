MarketLink — 60 SECOND START (judges / any PC)

NEED: XAMPP with PHP 8.2 or 8.3 + MySQL

----------------------------------------
EASIEST (recommended)
----------------------------------------
1) Unzip GitHub ZIP into C:\xampp\htdocs\
2) XAMPP: start Apache + MySQL
3) Open: http://localhost/Market-link-project-Techwiz-7-main/
   → site auto-imports database/marketlink.sql

----------------------------------------
OR manual SQL (phpMyAdmin)
----------------------------------------
1) http://localhost/phpmyadmin
2) Import → choose file:  database/marketlink.sql  → Go
   (file creates DB "marketlink" + all tables + demo data)
3) Open site folder in browser
