2) XAMPP: Apache + MySQL ON
3) Open ONE of these:

   http://localhost/Your-Folder-Name/import-db.php
   → click "Import marketlink.sql"

   OR just:
   http://localhost/Your-Folder-Name/
   → auto setup

DO NOT use phpMyAdmin Import if it shows "Unexpected character"
(that is a Windows encoding bug). Use import-db.php instead.
