MarketLink — 60 SECOND START

NEED: XAMPP PHP 8.2/8.3 + MySQL ON

A) AUTO (best)
1) Unzip ZIP into C:\xampp\htdocs\
2) Open: http://localhost/Your-Folder-Name/

B) phpMyAdmin SQL import
1) http://localhost/phpmyadmin
2) Import tab
3) Choose file: database/marketlink.sql  (or marketlink.sql in root)
4) Character set of the file: utf-8
5) Click Go
6) Open the site in browser

Demo:
farmer@marketlink.com / Farmer@123
customer@marketlink.com / Customer@123
admin@marketlink.com / Admin@123

If phpMyAdmin says "Unexpected character" / 703 errors:
you opened a UTF-16 copy. Re-download fresh ZIP from GitHub and import again with charset utf-8.
