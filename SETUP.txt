MarketLink — ZIP / XAMPP (testers)

GitHub ZIP me "vendor" folder nahi aati. Sirf EK dafa setup chalao.

========================================
1) Folder ko C:\xampp\htdocs\ me rakho
2) XAMPP me Apache + MySQL ON karo
3) setup.bat pe DOUBLE-CLICK (internet pehli dafa)
   YA browser: http://localhost/Your-Folder/install.php
4) Done. Site kholo:
   http://localhost/Your-Folder-Name/
========================================

Kuch aur manually nahi chalana — database + seed automatic.
